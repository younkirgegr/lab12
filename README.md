## Технологии
- Vue 3 (Composition API)
- Pinia (стейт-менеджмент)
- Vue Router
- Vite

## Установка
1. `npm install`
2. `npm run dev`

## HomeView
Главная страница с информацией о гончарной мастерской.
Использует статический контент для описания услуг и преимуществ мастерской.

## ProductsView
Просмотр керамических изделий через PotteryStore.fetchProducts().
Используется Pinia для управления состоянием и загрузки данных (onMounted).

## OrderView
Форма заказа изделий с отправкой данных через PotteryStore.submitOrder().
Валидация формы и обработка состояния отправки.

## Хранилище (Pinia)
Файл: src/stores/potteryStore.js
Содержит:

- Состояние: список изделий, статус загрузки
- Действия:
    fetchProducts() - загрузка изделий

    submitOrder() - отправка заказа

## API
Для демонстрации работы с API используются мок-данные:
- Список изделий (имитация API-запроса)
- Отправка заказа (имитация POST-запроса)
